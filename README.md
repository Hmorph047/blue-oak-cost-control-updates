# Blue Oak Cost Control Updates

This public repository is the signed software-update channel for Blue Oak Cost Control.

It contains only the Sparkle appcast and published application installers. It does not contain application source code, company databases, project records, proposals, photographs, credentials, or encryption keys.

Update archives are signed with Blue Oak's Sparkle EdDSA key. Production installers are also Developer ID signed and notarized by Apple before publication.
